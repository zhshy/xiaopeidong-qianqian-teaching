# 浅浅地教语文（肖培东）

> 肖培东“浅浅地教语文”的课堂艺术库。贴着文本语言行走，从字词句篇切入，靠朗读、提问、课堂生成推进。

## 功能

- 设计一节课的导入、提问、朗读环节
- 判断课堂是否"教得浅而不到""上得太满或太飘"
- 寻找教学出口，准备课堂实录或公开课
- 改造以教师讲解为主的课堂

## 课堂四步

**找教学出口 → 从字词句篇切入 → 朗读贯穿始终 → 课堂生成**

"教学出口"是从文本中长出来、又能带着学生往里走的入口。判断标准：这个问题能不能"贴着文本语言行走"——需要离开文本才能回答的问题，不是好出口。

| 文件 | 内容 |
|---|---|
| `SKILL.md` | 五条理念、课堂四步、六种课堂艺术、十六个课例索引、规则 |
| `references/classroom-checklist.md` | 六维课堂自查表 + 一节课设计模板 + 评课观察记录表 |

## 六维课堂自查

| # | 艺术 | 自查问题 |
|---|---|---|
| 1 | 课堂导入 | 导入是否从文本里长出来？还是硬贴背景介绍？ |
| 2 | 提问 | 问题是否具体到语言层面？有没有变成"是不是""对不对"？ |
| 3 | 掌控 | 学生回答偏离时，是直接否定还是顺着引导回来？ |
| 4 | 朗读指导 | 每次朗读都有明确的依据和目的吗？ |
| 5 | 语言表达 | 教师课堂用语是否干净、贴文本？ |
| 6 | 文本解读 | 是否贴着语言走，还是从概念到概念？ |

## 来源

提炼自肖培东《我就想浅浅地教语文——肖培东语文课例品读》（长江文艺出版社，2016，ISBN 9787535485137），含钱梦龙、黄厚江、王崧舟、王君等 16 位专家逐篇点评。

**本技能不含课例实录原文**，只提供课例索引与要点，需要具体实录时请引原书页码。

## 一条容易被误读的

**"浅"不等于简单。** 浅是入口的姿态，不是结果的深度。肖培东的课是安静的、贴着文本走的；小组讨论、多媒体、情境表演都不是必需品。

## 安装

```bash
git clone https://github.com/zhshy/xiaopeidong-qianqian-teaching.git
```

将技能目录放入 WorkBuddy 的用户级技能目录：

- **Windows**：`C:\Users\<用户名>\.workbuddy\skills\`
- **macOS / Linux**：`~/.workbuddy/skills/`

重启 WorkBuddy 后生效。

## 什么是 Skill

Skill 是给 AI 助手加载的专业知识包：一个 `SKILL.md` 定义触发条件与工作流程，`references/` 存放按需加载的细节文件。加载后助手会按既定流程工作，而不是即兴发挥。

本仓库技能遵循 Agent Skills 规范：YAML frontmatter + Markdown 正文 + 渐进式披露的 references。
