# 课堂自查表与设计模板

从肖培东的六种课堂艺术和"浅浅地教"的理念转化而来，用于**备课后自查**和**听课后评课**。

---

## 一、课前：六个设计动作

### 动作 1｜找教学出口

- [ ] 出口明确定位在文本的哪个位置（哪一句/哪个词/哪个标点）？
- [ ] 这个出口能不能带着学生"贴着文本语言行走"？
- [ ] 如果一个问题需要离开文本才能回答 → 换掉它

### 动作 2｜确定字词句篇的切入点

- [ ] 有没有找到"一望而知其实一无所知"的词句？
- [ ] 切入点是否具体到**语言**层面（而非"理解作者情感"这类抽象目标）？
- [ ] 词语的理解是否放在语境中进行（而非先给字典义再读）？

### 动作 3｜设计朗读

对每一次朗读，都要能回答：
- [ ] **为什么读**（暴露理解？促发新理解？品味语言？）
- [ ] **怎么读**（哪里慢/重/停，依据是什么）
- [ ] **读完做什么**（朗读之后如何推进课堂）

三个问题只要有一个答不上来，这个朗读就是形式化的，应删掉。

### 动作 4｜准备核心提问

- [ ] 问题是否具体、开放（避开"是不是""对不对"）
- [ ] 问题是否能引出不同的回答（有讨论空间）
- [ ] 有没有准备**追问**的后续问题（学生答出来后往哪里走）

### 动作 5｜预判生成点

- [ ] 哪些地方学生可能答偏？我怎么顺着引回来？
- [ ] 哪些地方学生可能"说不出来"？这恰恰是教学点吗？
- [ ] 我预备在哪个环节让课堂慢下来？

### 动作 6｜检查课堂容量

- [ ] 预设的环节是否过多（宁可少而透）？
- [ ] 是否留够了学生活动的时间？
- [ ] 依据课标"不任意增加学生的学习负担"，有没有做无意义的加量？

## 二、课后：六维自查表

按肖培东的六种课堂艺术逐项打分（1–5 分），并写下具体证据。

| 维度 | 自查问题 | 分 | 证据（具体到某句/某分钟） |
|---|---|---|---|
| **导入** | 导入是否从文本里长出来？ | | |
| **提问** | 问题是否具体到语言层面？ | | |
| **掌控** | 学生偏题时是否顺着引导而非直接否定？ | | |
| **朗读** | 每次朗读是否都有明确依据和目的？ | | |
| **语言** | 教师用语是否干净、贴文本、无多余评价？ | | |
| **解读** | 是否贴着语言走，而非从概念到概念？ | | |

**特别注意"语言"这一项**——这是最容易被忽略的。肖培东课堂的一个显著特点是**教师话说得少而准**，不做"你真棒""很好，请坐"这类无信息量的评价语。自查时可以统计：一节课里教师的评价语有多少句是**真正推进了课堂**的？

## 三、常见问题诊断

| 课堂症状 | 诊断 | 改法 |
|---|---|---|
| 学生很活跃，但读完课文就忘了 | 浅而不到 | 检查有没有"教到该感受的思想"——活动本身不是目的 |
| 课上得深刻，学生听不懂 | 深而不到 | 换一个浅的入口：从具体的字词句进 |
| 课堂很满、很赶 | 环节过多 | 砍掉一半环节，让核心环节慢下来 |
| 朗读读了但没效果 | 朗读无依据 | 每次朗读前明确问"为什么这里要这样读" |
| 学生回答问题后课堂就"停"了 | 缺追问 | 准备 2–3 个梯度的追问 |
| 用了很多多媒体/表演 | 形式化 | 先问：这些手段替代了什么语言活动？能否删掉 |
| 教案完成度很高但课堂很干 | 预设压倒生成 | 留出在学生的真实反应上做文章的空间 |

**最后一项最关键**——这直接对应王荣生"理解感受必须有明显变化"的原则。如果记录不出具体变化，这节课就没有真正发生。
